## Légende

- `[À REMPLIR]` — information manquante, à décider
- `[HYPOTHÈSE]` — idée discutée, **pas validée**
- `[VALIDÉ]` — décidé par l’équipe
- `[ALPHA]` — prévu pour la version alpha
- `[PLUS TARD]` — hors scope alpha

## Comment utiliser ce GDD

1. Commencer par [01 — Vision](01-vision.md).
2. Quand une décision est prise : la reporter dans la bonne page et marquer `[VALIDÉ]`.
3. Garder les points encore ouverts uniquement dans [08 — Ouvertes & roadmap](08-ouvertes-et-roadmap.md).
4. Mettre à jour les diagrammes Mermaid si la loop change.
